Test_Python / Misc

This page explains the miscellaneous Python examples stored in the Misc directory of the Test_Python repository. The examples cover Python fundamentals, operating-system tasks, networking, cryptography, log analysis, reconnaissance, email automation, data handling and unit testing.

Some scripts interact with the operating system, network, credentials or external services. Those examples are documented for educational review only and are not executed in the browser.

Topics covered

Python basics

Loops, tuples, random values, input handling and small text-based programs.

Cryptography

Simple Caesar-cipher examples that demonstrate character substitution.

Operating system

Platform information, CPU usage, disk space, directory creation and file operations.

Networking

Hostname lookup, URL checking and network-related examples.

Log analysis

Reading logs and experimenting with traffic or denial-of-service indicators.

Reconnaissance

Introductory reconnaissance scripts for authorised security learning.

Testing

Small pytest examples for validating arithmetic functions.

Packaging

Notes about PyInstaller, NSIS and turning Python scripts into executables.

How to use the repository

  1. Install Python 3.
  2. Clone or download the repository.
  3. Open a terminal in the selected example folder.
  4. Review the source code before execution.
  5. Install only the packages required by that example.
  6. Run security and networking examples only in an authorised lab environment.
git clone https://github.com/akjalbani/Test_Python.git
cd Test_Python/Misc
python path/to/example.py
